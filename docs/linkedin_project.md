# LinkedIn Project

## Name

Brazilian Power System Analytics Dashboard

## Nome em Portugues

Dashboard do Sistema Eletrico Brasileiro

## Short Description

Analytical dashboard project for the Brazilian power system, integrating official ANEEL, ONS and CCEE public datasets to analyze installed capacity, effective generation, SIN load, renewable expansion, distributed generation and geography using Python, dimensional modeling and Power BI.

## Full Description

I developed a reproducible analytics project for the Brazilian power system using official public data from ANEEL, ONS and, when available, CCEE. The project separates installed capacity, effective generation, SIN load, distributed generation and PLD so that MW, MWmed, MWh and R$/MWh are correctly interpreted. It includes Python extraction and validation scripts, a dimensional model, DAX measures, Power Query documentation, Power BI page specifications, dashboard mockups and portfolio material.
