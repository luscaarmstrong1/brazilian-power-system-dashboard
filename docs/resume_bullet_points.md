# Resume Bullet Points

## Versao Curta

Desenvolvi um dashboard analitico do sistema eletrico brasileiro em Power BI e Python, integrando dados publicos oficiais de capacidade instalada, geracao, carga do SIN, renovaveis e geracao distribuida.

## Versao ATS

Projeto de Energy Analytics e Power Systems com Python, Power BI, DAX, Power Query e modelagem dimensional, utilizando dados oficiais da ANEEL, ONS e CCEE para analisar capacidade instalada, matriz de geracao, carga do Sistema Interligado Nacional, geracao distribuida/MMGD, fontes renovaveis, expansao e distribuicao geografica.

## English Version

Built a Brazilian Power System Analytics Dashboard using Python, Power BI, DAX and dimensional modeling, integrating official ANEEL, ONS and CCEE public datasets to analyze installed capacity, effective generation, SIN load, renewable expansion, distributed generation and geographic concentration.
