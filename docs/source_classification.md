# Source Classification

The dashboard stores the original source field and a grouped analytical source. The grouping is transparent and can be revised without changing raw data.

| Token | Grouped source | Technology | Renewable |
|---|---|---|---|
| HIDRO, UHE | Hydro | Hydraulic | Yes |
| PCH, CGH | Small Hydro | Hydraulic | Yes |
| EOL, EOLICA | Wind | Wind | Yes |
| UFV, SOLAR | Solar | Solar photovoltaic | Yes |
| BIO, BIOMASSA | Biomass | Thermal renewable | Yes |
| GAS | Natural Gas | Thermal | No |
| OLEO, PETROLEO | Oil | Thermal | No |
| CARVAO | Coal | Thermal | No |
| NUCLEAR, UTN | Nuclear | Nuclear | No |
| UTE without specific renewable fuel | Thermal Other | Thermal | No |

Nuclear is low-carbon but not classified as renewable. MMGD is kept separate from centralized installed capacity.
